# Eigene Fotos

Hier die Fotos vom Laden ablegen und am jeweiligen Element im `index.html`
die Variable `--foto` setzen, z. B.:

```html
<figure class="gal-stueck gal-stueck--a t-senf" style="--foto:url('assets/img/spiess.jpg')">
```

Solange hier nichts liegt, zeigt die Seite die gezeichneten Grafiken —
sie sieht also zu keinem Zeitpunkt kaputt aus.

Empfohlene Größen: quer ca. 1600 × 1200 px, hoch ca. 1200 × 1600 px, JPG.
