# Fotos für die Vorschau

Leer — und das ist in Ordnung. Fehlen die Dateien, zeigen beide Entwürfe die
gezeichneten Szenen und weisen oben links darauf hin.

Willst du in der Vorschau schon echte Fotos sehen, lege sie hier ab. Die Namen
und Formate stehen in `../../fotos/README.md`:

```
01-tal.jpg   02-haus.jpg   03-foyer.jpg
04-zimmer.jpg   05-speisesaal.jpg   06-garten.jpg
```

Der Ordner ist bewusst getrennt vom Ordner der echten Seite, damit sich
`vorschau/` als Ganzes hochladen lässt, ohne dass Pfade ins Leere zeigen.
